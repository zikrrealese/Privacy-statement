# Privacy Policy – Zikr

**Last Updated: October 24, 2026**

## 1. Introduction

Zikr is a simple dhikr counter designed for Huawei smartwatches. This Privacy Policy explains how the application handles user information.

## 2. Data Collection

Zikr does not collect, store, or transmit personal information. The application does not require users to create an account or provide personal details.

## 3. Data Sharing

Zikr does not sell, share, or transfer personal information to third parties.

## 4. Permissions

The application uses its counting functionality and vibration feedback to provide its intended features. It does not request personal information for these functions.

## 5. Data Security

Since Zikr does not collect or transmit personal information, it does not maintain a personal information database.

## 6. Children's Privacy

Zikr does not knowingly collect personal information from children or other users.

## 7. Changes to This Policy

This Privacy Policy may be updated if the application's features or data practices change. Any updated version will be published at the same location.

## 8. Contact

For questions about this Privacy Policy, please contact the application developer through the contact information provided on the application's store listing.
